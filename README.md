# Portfolio de Aimar Canino Almeida

Portfolio personal estático, preparado para GitHub Pages.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: diseño responsive y estilos.
- `script.js`: interacciones, selector de idioma y tema.
- `assets/`: retrato, CV y favicon.

## Publicación en GitHub Pages
Sube el contenido de esta carpeta a la raíz del repositorio que publica el portfolio, conservando la estructura de `assets/`. Confirma los cambios y espera a que GitHub Pages termine el despliegue.

## Funciones
- Diseño adaptable a escritorio y móvil.
- Selector de idioma español / inglés / neerlandés (ES / EN / NL).
- Modo claro y oscuro.
- Filtros de experiencia, navegación rápida y progreso de lectura.
- Enlace de contacto que abre la redacción de Gmail con el destinatario preparado.

## Nota sobre PC PILOT
PC PILOT aparece como proyecto principal y está identificado como proyecto en desarrollo. La ilustración del panel es una representación visual creada con CSS, no una captura de la aplicación.
